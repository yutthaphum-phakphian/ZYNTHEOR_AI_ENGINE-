# Global Intelligence Benchmark

ZYNTHEOR measures intelligence through reproducible evaluation: how well it performs against established standards and competing systems. **Current status: all categories `NOT_EVALUATED`.**

## Arenas

| Arena | Evaluation focus | Candidate benchmarks |
|---|---|---|
| General Intelligence | Knowledge and broad problem solving | MMLU-Pro |
| Research & Knowledge | Web research and retrieval | BrowseComp |
| Advanced Reasoning | Mathematics and scientific reasoning | AIME, GPQA Diamond |
| Multimodal Intelligence | Visual and multimodal understanding | MMMU, MathVista |
| Agentic Capabilities | Real-world multi-step tasks | WebArena, OSWorld |
| Coding Intelligence | Software engineering problem solving | SWE-bench Verified |
| Thai Intelligence | Thai language, reasoning, technical understanding | ZYNTHEOR Thai Benchmark |

Benchmark selection is subject to dataset licensing, access conditions, suitability and reproducibility.

## Required metrics
Accuracy · Task Success Rate · Hallucination Rate · Evidence Accuracy · Tool Execution Success · Reliability · Failure Rate · Latency · Cost per Task

## Benchmark integrity
Every reported score must include: model and version; benchmark and dataset version; evaluation configuration; tool access and execution conditions; number of test samples; scoring methodology; raw results; reproducible test records.

Unevaluated categories are marked `NOT_EVALUATED`. No estimated, fabricated or simulated score may be presented as a real result.
