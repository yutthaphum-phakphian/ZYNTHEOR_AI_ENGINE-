# Thai Understanding 6 ด้าน
- Thai Understanding: เข้าใจคำสั่งภาษาไทย
- Mixed Language: ไทยปนอังกฤษ+ศัพท์เทคนิค
- Intent Detection: เข้าใจเจตนา
- Context Awareness: จำบริบท
- Thai Code Assistance: อธิบายโค้ดเป็นไทย
- Thai Response: ตอบไทยธรรมชาติ

ตัวอย่าง: "ช่วยตรวจสอบโค้ดนี้ว่ามีอะไรผิด" / "แก้เฉพาะส่วนที่มีปัญหา อย่าไปแตะไฟล์อื่น" / "สร้างหน้า Login ที่รองรับมือถือ" / "ช่วยดูว่าทำไม API ถึงเชื่อมต่อไม่ได้"
