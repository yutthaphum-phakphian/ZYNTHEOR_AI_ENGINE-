# ZYNTHEOR Pilot Feedback Collection Specification

## 1. Feedback Channels & Metrics

1. **In-App Issue Reporter**: Integrated modal for bug reports, UI feedback, and AI response quality rating.
2. **System Error Dashboard**: Persistent logging of uncaught API and app errors (`/api/diagnostics/errors`) categorized by level and endpoint.
3. **Audit Ledger Logs**: Forensic tracking of user approvals, rollbacks, and diff applications.
